\section{Indicaciones}
\begin{frame}{Indicaciones}
\small
Resuelva cada sistema mediante eliminación de Gauss o Gauss--Jordan. En cada caso:
\begin{enumerate}
\item escriba la matriz aumentada;
\item reduzca la matriz por operaciones elementales;
\item determine si el sistema es compatible determinado, compatible indeterminado o incompatible;
\item si existen variables libres, escriba la solución en forma paramétrica.
\end{enumerate}
\medskip
Los bloques incluyen sistemas rectangulares: el número de ecuaciones no necesariamente coincide con el número de incógnitas.
\end{frame}
